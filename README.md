# Translate Shortcut for Mac

面向 macOS 的快捷翻译项目，目前处于初始化阶段。

## 获取项目

```bash
git clone https://github.com/yza167-jp/translate_shortcut_for_mac.git
cd translate_shortcut_for_mac
```

## 开发状态

仓库当前包含项目说明和基础 Git 忽略规则。应用源码、开发环境要求、构建步骤和使用指南将在后续开发中补充。

## Git 忽略规则

`.gitignore` 覆盖 macOS 系统元数据、Swift/Xcode 构建产物、用户专属工程状态和本地环境文件。项目源码、Xcode 工程文件及共享配置可以正常纳入版本控制。
